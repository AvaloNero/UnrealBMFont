# Support

Use repository discussions for setup questions and the issue tracker for reproducible defects or feature proposals.

A useful support request includes:

- Unreal Engine version and whether it is launcher or source-built.
- Operating system and target platform.
- Descriptor format (`text`, `XML`, or `binary v3`).
- Import log lines from `LogUnrealBMFont`.
- A minimal redistributable `.fnt` and atlas, when licensing permits.
- Whether the problem occurs during import, layout, Editor preview, cook, or packaged runtime.

General Unreal Engine installation, renderer, or image-decoder problems may need to be reported to Epic rather than this project.
