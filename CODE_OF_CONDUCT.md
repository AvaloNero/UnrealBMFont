# Code of conduct

Unreal BMFont contributors and maintainers are expected to keep project spaces constructive, specific, and welcoming.

- Discuss code and evidence, not personal attributes.
- Assume good faith while still asking for reproducible details.
- Do not harass, threaten, discriminate, publish private information, or use sexualized language or imagery.
- Respect licenses and the ownership of fonts, atlases, test data, and source code.
- Maintainers may edit, hide, or remove harmful content and may restrict repeated abusive participation.

Report conduct concerns through a private maintainer or repository security channel. Maintainers should disclose conflicts of interest and handle reports as confidentially as practical.
